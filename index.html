Projects

01
Live GitHub

Project Alpha

A full-stack SaaS dashboard with authentication, billing, and real-time data visualization. Built from scratch to production in 6 weeks.

Next.js Stripe Postgres

The client was running billing and usage tracking through a patchwork of spreadsheets and a third-party dashboard that didn't talk to their own database, so support tickets about incorrect invoices were a weekly occurrence.

Designed a Postgres schema that treated usage events as the source of truth, then layered Stripe's metered billing on top so invoices generate directly from real usage instead of a manually maintained count. Built the dashboard in Next.js with server components for the data-heavy views to keep first load fast.

Billing-related support tickets dropped to near zero after launch, and the client could finally see real-time usage per customer instead of waiting on end-of-month exports.

02
GitHub

Open Source CLI Tool

Auto-generates TypeScript types from REST API responses. Picked up 400+ GitHub stars in the first month.

TypeScript Node.js CLI

Every project on the team hand-wrote TypeScript interfaces for API responses, and they'd silently go stale the moment the backend changed a field — bugs that only showed up at runtime.

Built a CLI that hits a given endpoint, infers the shape of the JSON response, and generates matching TypeScript types automatically, with a watch mode for local development. Published it as an open-source npm package with a small, dependency-light core so it'd be easy for other maintainers to audit.

Picked up 400+ GitHub stars in its first month and got adopted by a couple of other teams outside the original project, without any marketing beyond a single Show HN-style post.

Live

E-commerce Platform

Headless store with custom CMS, inventory management, and payment processing. Handles 500+ orders per day.

React Sanity Stripe

The client's existing store was locked into a template-based platform that couldn't support the custom product configurator their catalog needed, and every content change required a developer.

Went headless: React storefront on the frontend, Sanity as the content layer so the client's team could edit products and pages themselves, and Stripe handling payments and subscription billing for a recurring-order option.
